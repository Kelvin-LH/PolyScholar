# 数据模型状态

`001_initial.sql` 是最初领域参考设计，当前桌面程序不加载它；其中翻译块、模型摘要与引用样式仍是未完成目标。

运行时 SQLite v4 由 `polyscholar/store.py` 与 `polyscholar/document_ir.py` 管理：原有文献/设置/任务/审计和集合/成员关系，新增解析版本、当前版本、页面、文本块、笔记结论与证据关系。跨文献与解析版本的组合外键防止串联来源。v1/v2/v3 升级前备份，原文文件和已有历史保留。

解析版本保存源文件 SHA-256 与解析器标识；页面保存裁剪/旋转/实际矩阵，块坐标使用可见页左上原点的归一化坐标。每次解析产生新版本，旧块保留；旧证据显示失效，不自动迁移到新块。

原文摘录必须逐字属于指定文献文本块。`evidence_linked` 只表示摘录关联通过，不表示笔记结论真实；无证据使用 `insufficient_evidence`。当前实现支持本地原生文字解析与人工证据笔记，扫描件 OCR、科学结构分类、模型摘要、段落对齐与块翻译仍待实现。
