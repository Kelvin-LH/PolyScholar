# 个人桌面 UI 设计规范

日期：2026-10-02。本文是实施规范；控件是否可用以运行时真实能力为准，不表示所有功能已经实现。产品范围沿用 [需求基线](02-requirements.md) 与 [联网范围](09-local-and-network-scope.md)。

新增要求：文献管理对标 Zotero 的个人本地工作流，具体能力与验收分层见 [Zotero 对标矩阵](12-zotero-parity.md)。基础文献列表不能称为 Zotero 功能对齐。

## 工作区与视觉系统

面向 Windows、macOS、Linux 的个人桌面工具，应用使用 Python/PySide6 Widgets 原生控件直接调用本机 Python 服务，发行自带 Python 运行组件；没有浏览器产品、账户、团队空间或云同步。

- 白色背景，浅灰分割线，深绿色主操作，深灰正文；信息密度适中，以阅读和表格操作为中心。
- 左侧导航宽 220px：文献库、双语阅读、翻译任务、证据摘要、引用导出、设置。当前文献上下文跨屏保留。
- 顶部显示页面标题、当前文献或库内搜索；右侧只有与当前任务有关的操作。底部显示本地存储状态、实际运行任务数和应用版本，不展示虚构实时指标。
- 大窗口使用主工作区与右侧上下文面板；窗口低于 1180px 隐藏非必要列、右栏变抽屉；低于 960px 原文/译文改为切换视图。侧栏可折叠，不将产品转为移动端网站。
- 字体采用系统中文字体回退，正文 14–16px，阅读正文 16–18px，控件点击区域至少 32px；保留系统缩放。绿色之外使用文字与图标表达状态。
- 按钮有默认、hover、focus、disabled、busy 状态；操作进行中防止重复提交。无实现能力的按钮禁用并就近说明，不能点后显示成功。
- 原型示例必须标为“设计示例”，不得自动混入真实文献库；首次运行显示空库、零任务、零摘要。演示只能单独切换，退出后恢复真实数据。

建议颜色：主色 `#176B52`，主色浅底 `#EDF6F1`，正文 `#202C27`，次要文本 `#5F6C65`，边线 `#E4EAE6`，工作区底 `#F6F8F6`，警告 `#9A5B13`，错误 `#B43E36`。最终对比度须实测满足 WCAG AA；不能只依据颜色名称认定无障碍。

## 界面清单与交互

### 1. 首次启动与文献库

空态写“导入第一篇本地 PDF”，提供导入文件与手动录入元数据；说明文献保存在本机。拖入文件和原生文件选择对话框执行相同校验，不读取任意目录或自动公开附件。

文献库采用表格，列为标题、作者、年份、标签、译文状态、导入日期；标题可以两行，文件名作为次要信息。搜索框仅搜索本机已有条目，排序和筛选不发起学术搜索。选中行后右栏显示元数据、附件、文件哈希摘要和最近笔记；双击进入阅读。

文献库内部采用 Zotero 类似的三栏工作流：左侧集合树与标签筛选，中间条目及子附件列表，右侧“信息/笔记/标签/附件”。集合可有子集合，同一条目可属于多个集合且不复制文件；“从集合移除”“从库删除”是不同操作。左侧预留全部文献、未分类、重复候选、回收站入口，但只有对应查询/恢复能力实现后启用；未实现不得生成假条目。标签筛选与本机搜索联合生效，空结果显示当前集合、关键词与标签及清除筛选。

条目信息以文献类型驱动字段：首批期刊文章、会议论文、图书、学位论文，作者支持有序列表及个人/机构类型，按字段保存出版物、卷期页码、出版日期、DOI/ISBN。多个附件有原文/译文/补充材料角色及来源版本。暂未实现的类型和多附件关系必须明确，不能用一个标题/作者字符串冒充完整管理。

导入流程：文件选择 → 格式/体积校验 → 本地复制与 SHA-256 去重 → 保存成功后新增行。重复导入显示已有条目和“打开”，相同 DOI 的不同版本不能自动合并。错误保留文件名与安全原因，不能把失败导入当作成功条目。

元数据编辑面板支持标题、作者、年份、DOI、出版物和标签；“查询 DOI”单独触发联网，展示仅发送 DOI 的提示及字段差异，用户确认后合并。未接入 DOI 功能时禁用查询，仍允许手工保存。

删除分为移出文献库与清理应用管理的附件/缓存，显示共享附件引用；不删除用户原始路径文件。任何未实现的破坏性操作保持禁用。

验收：空库不显示示例；导入失败无虚假记录；重启后条目保持；库搜索不联网；重复文件复用并可打开；元数据人工修改不会被在线查询静默覆盖。

Zotero 对标增量验收：跨两个集合添加同一条目后总库仍只有一个条目；移除一个集合成员不影响另一集合；删除集合不删文献；标签组合与搜索结果可复现；预印本与正式版本不会因 DOI 相同静默合并。实现状态逐项记录于对标矩阵。

### 2. 双语阅读

工具条包含返回库、文献标题、页码/总页数、缩放、原译对照模式与证据面板开关。主区域原文/译文左右对照，保留公式和原图；右栏在术语、图文注释、笔记中切换。可折叠目录放于原文侧。

只有本机真实 PDF 被解析后显示页数与画面。未选择文献提示从库中打开；解析中显示阶段；加密、不支持或损坏 PDF 显示可恢复错误。PDF 渲染未接入时明确显示“PDF 页面渲染待实现”，不将文件名或假页面包装成阅读成功。

真实译文产物出现后提供“导出译文 PDF”，同时显示任务、引擎及产物文件名；多产物需选择。导出走原生保存对话框，在后端校验源产物路径、PDF 文件头与输出哈希，实际写入完成才显示成功；取消、磁盘满和无权限均不显示成功。没有真实译文时按钮禁用。只复制已有产物，不宣称重新排版或无损；原 PDF 永不覆盖，目标与原件相同须拒绝。

选择文字后浮动操作支持翻译选段、加入笔记；选段须有页码、block ID 和原文哈希。译文未生成时显示“尚未翻译”，翻译失败块显示原因并保留原文；译文编辑有版本与保存状态。同步滚动按真实块映射执行，找不到映射须提示。

图中文字注释从选定区域执行本地 OCR；先显示原词、框坐标、置信度与人工校正，再独立授权文本翻译。无 OCR 后端时禁用。图片外发默认关闭；用户选视觉模型时另行确认选区。

验收：页码与文件一致；PDF 原件字节不变；无真实段落映射不能伪造同步定位；失败译文不覆盖原文；右栏来源跳转只接受有效页码/块。

### 3. 翻译任务与创建任务面板

创建面板字段为文献、BabelDOC/PDFMathTranslate 引擎、语言、页范围、提供商、endpoint、模型、输出目录与允许的数据处理范围。按用户本轮授权，模型 API 外发与模型/字体下载默认允许，不设置每次任务必须手动勾选的复选框；任务请求仍携带两个 true 授权字段，后端保持契约校验。引擎可用性从固定版本探测获取，缺少环境时显示安装指引，不能显示“已就绪”。

范围说明展示实际目的地、发送内容及页范围、是否图片、资源下载范围；不再要求重复手动确认已授权的文本 API 和资源下载。页码范围不等于已验证上游外发隔离；当前无法确认严格范围时显示“上游载荷范围尚未验证”，不能承诺仅发送所选页。

费用栏仅使用真实供应商价格与估算；缺少价格或 token 统计显示“费用未知”。尚无预算网关时标明“未实现硬预算限制”；不提供看似有效的硬限额控件。用户取消本机进程时提示在途远端请求仍可能计费。

任务表显示文献、引擎、状态、开始时间、实际阶段、输出。queued/running/paused/completed/failed/cancelled 使用不同文字标签。引擎无法提供百分比时显示阶段或不定进度，不随机增加百分比。成功要求进程正常退出、输出存在且校验通过；部分完成与失败分开呈现。

暂停、恢复、重试仅在后端真实支持时启用。取消须作用于进程树，操作中的状态先为“正在取消”，收到退出确认后为 cancelled。重新运行不得覆盖已有输出目录。

验收：缺少引擎或有效输入不得启动；后端拒绝与授权契约不符的请求；任务状态由后端事件驱动；无文件不能显示成功；取消后临时密钥清理；错误不展示原始密钥或论文正文；重启恢复能力未实现时明确说明。

### 4. 证据摘要

顶部选择当前文献、结构化摘要范围与模型；正文依次为背景、方法、数据、结果、局限。每条结论呈现正文、来源页码/块、原文摘录与人工备注。右侧为证据预览，点击来源定位阅读页。

空态“尚无证据摘要”，只有真实结构化结果才能生成卡片；无证据时标记“来源缺失，需核对”，不能补造页码。摘要说明为模型辅助阅读内容，需要用户核查，界面不设“科学真伪”按钮或论文代写入口。

摘要按用户允许的模型 API 处理范围执行并展示输入范围，不强制重复文本 API 勾选；按版本保存模型、输入修订和生成时间。没有摘要后端时生成按钮禁用。手动笔记与模型结论区分存储与显示。

验收：每条来源可校验且可定位；失效映射显示无法定位；模型输出不执行链接/脚本/文件操作；未接入能力不显示假摘要和假成功。

### 5. 引用导出

左侧选择本机条目，中间选择纯文本、BibTeX、RIS、CSL-JSON 与具体引用样式；右侧预览及字段缺失/转换损失。GB/T、APA、IEEE、Nature 仅在处理器和合法样式实际接入后启用。

格式化引用与交换格式导出分开。无真实引用处理器时不可把未经验证的字符串称为标准格式引用。导出走原生保存对话框，不自动上传；同名文件确认覆盖；成功须实际写入，取消保存不得 toast“已导出”。

验收：缺失字段不由 LLM 猜补；不同格式有明确说明；预览与导出一致；失败可重试且保留选择；用户论文不因软件 AGPL 被标为 AGPL 作品。

### 6. 设置与关于

分组为本地存储、模型 API、翻译引擎、模型/字体资源、联网权限、操作记录、关于与许可证。显示本机数据目录、容量与安全删除方式；没有账户入口。

API 配置支持提供商、HTTPS endpoint、模型与密钥输入；本地端点可明确使用 loopback HTTP。密钥掩码且服务不回传原值，不进入普通设置 JSON、数据库或日志；OS 凭据库未接入时保存密钥按钮禁用，不能悄悄明文持久化。连接测试说明是否实际联网及是否计费，未经用户操作不得测试。

Python 路径不作为普通用户必填项。选择翻译引擎后自动发现随包/应用管理环境，并探测固定版本，显示“已发现 BabelDOC 0.6.4”或真实缺失原因；同名 Python 可执行文件存在不足以认定可用。无法自动发现时显示设置指引。“高级设置”折叠区提供自定义解释器路径与重新探测，展开/保存后仍需后端核查，不能在导入文献时迫使用户理解 Python 环境。

缓存设置提供当前真实目录、“选择目录”“恢复默认”，分别说明永久文献库与可重建任务/资源缓存；修改目录不移动或删除原件。保存前检查本机目录及写权限，活动任务期间禁止迁移；现有缓存采用保留旧目录/明确确认迁移策略，不静默删除。若本轮只对新任务生效，界面需直说。引擎有自己的资源缓存时说明当前实际控制范围，不能承诺一个选项覆盖全部上游缓存。检查失败保留原配置；清理只处理确认的应用缓存，不允许清空任意父目录。

模型/字体展示实际安装状态、来源、许可、版本与校验信息；下载是独立动作，无包时显示未安装；不上传论文。导入本机资源应显示相同校验结果。

模型 API 与资源下载沿用用户已明确的默认允许；设置可提供关闭能力，DOI 独立控制，均不授权遥测、云 OCR 或同步。本地日志提供查看/清理；只记录最小化操作信息，不收集学生监控数据。关于页展示实际版本、AGPL 文本、上游通知、源码仓库与来源清单；不得把 AGPL 表述为禁止商用。

验收：读取设置不发请求；取消编辑不写入；密钥不可被日志/导出泄漏；离线状态清晰；没有秘密回传；许可链接可用。

## 共通状态、键盘和可访问性

各屏均覆盖 empty/loading/ready/partial/error/offline 状态。错误就近显示行动建议，toast 用于已确认的短反馈；长任务保留任务记录，不能依赖会消失的 toast。加载中不能丢失当前文献。

Tab 顺序和视觉顺序一致，所有操作有明确可访问名称，键盘焦点可见；抽屉关闭后焦点回到触发器。Esc 关闭未提交面板；编辑有未保存修改时提示。快捷键拟定 Cmd/Ctrl+O 导入、Cmd/Ctrl+F 当前本机搜索；只注册已实现的行为，避免拦截系统快捷键。

首轮以 1440×960、1280×800、960×720 和 200% 缩放验证；长中文标题、长路径、空作者、无 DOI、断网、磁盘满、进程错误必须纳入人工验收。操作系统原生文件对话框、Qt PDF 插件、系统缩放及辅助功能差异需要逐平台测试。


## 重复候选与合并面板

文献库提供本地候选及手动多选两个入口。候选显示原因和总数，全部元数据在合并预览内按纯文本完整显示；选择主条目及逐字段来源后，再核对影响范围。主PDF保留，其他主PDF转为补充附件；合并不可自动撤销，合并前快照仅供查看。取消或失败保留选择，关联数据变化要求刷新预览，不自动套用旧决策。后台操作复用主窗口IO；关闭后忽略晚回调，不另起未管理线程。
