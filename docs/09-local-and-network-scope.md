# 个人使用与联网范围

确认日期：2026-10-02。按用户最新澄清，允许模型 API、DOI 在线元数据查询，以及上游模型和字体下载。这替代“只允许模型 API 联网”的临时解释；不取消个人本地桌面、不采用 B/S 的约束。

## 允许的联网业务

| 业务 | 允许发送 / 接收 | 数据边界 |
|---|---|---|
| 模型 API 翻译、术语解释与总结 | 用户选择范围的文本；视觉模型仅在另行授权后接收选定图片 | 显示提供商与 endpoint、范围和费用；失败不自动改用其他提供商；不以自建云网关转发 |
| DOI 在线元数据查询 | DOI 等查询标识，接收作者、标题、出版信息等元数据 | 不上传 PDF、批注、笔记、完整文献库；查询本身可能透露阅读兴趣，用户可关闭并手工录入 |
| 模型和字体下载 | 获取本地引擎需要的资源文件 | 不上传文献或研究数据；显示来源、大小、用途及许可，记录版本和校验信息；已缓存资源应复用 |

所有结果、文献、译文、批注、术语、缓存、数据库和操作记录保存在本机。PDF 解析、OCR、图文定位、证据锚点校验、引用生成和导出在本机执行。模型 API 的输入由外部提供商处理，不能因此宣称所有内容绝不离开本机；发送范围必须让用户明确知晓。

DOI 元数据查询不是学术搜索或论文下载平台；不提供关键词检索聚合、抓取全文或绕过访问授权。模型/字体下载是本地资源准备，不扩展为远程文档处理。引用样式可随包提供或本地导入，不默认增加其他在线服务。

## 明确排除

- 学术搜索平台、盗版下载。
- 替作者代写论文、自动判断科学结论真伪。
- 强制监控学生、自动将私人文献公开。
- 多用户商业 SaaS、浏览器端、团队服务、账户云同步。
- 云端文献存储、云 OCR/解析、后台遥测及内置云端诊断上传服务。

AGPL 仍允许商业使用；“不做多用户商业 SaaS”是本项目产品范围，不是额外许可限制。源码公开与 GitHub CI 只涉及开发源代码和合成测试，不能夹带私人文献、密钥或用户数据库。

## 验收要求（待实现，不是已验证结果）

1. 已准备资源且关闭 API/DOI 查询时，阅读、文献管理、OCR、引用与导出可离线完成；资源缺失提示下载或本地导入，不擅自上传文档。
2. 分别检查真实 BabelDOC、PDFMathTranslate 的冷缓存、资源下载、错误重试和取消路径，确认资源请求没有文献载荷，没有额外云存储/遥测请求。
3. DOI 查询只携带必要标识；元数据不直接覆盖人工修订，不自动下载论文。
4. API 请求与授权范围匹配；验证视觉输入、跨页上下文及上游重试，不以“选了三页”就假定其他内容绝不外发。
5. 用户可以查看模型/字体来源和许可；下载资源验证版本与完整性。云业务可关闭，本地资料可导出/删除，不依赖账户。

当前实验 CLI 的资源下载标志符合允许准备本地模型/字体的方向，但尚未完成以上真实联网行为与数据载荷检查。现有参数解析/合成测试不能替代这项验收。

## arXiv 导入与 HTML 译文

用户主动导入时向 arXiv 发送编号，下载元数据、PDF 或 HTML；HTML 图像仅缓存当前论文页面同源的官方 HTTPS 位图，受数量和大小限制。阅读和导出不再请求远程资源，不上传本机文献给 arXiv。HTML 按全文发送文本至所选模型 API，公式占位保留；不支持的图片明确显示占位。

Agent 评阅与报告保存在本地，分数不代表科学结论真伪。CLI/MCP 与桌面共用库锁，GUI 占用时 CLI/MCP 拒绝修改。
