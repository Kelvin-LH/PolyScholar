# 产品需求基线 v0.1

## 固定产品范围

个人本地桌面使用，不采用 B/S。允许模型 API、DOI 在线元数据查询、模型和字体下载；这些联网能力不授权云端存储、远程 OCR、遥测或账户同步。数据发送范围、下载校验与验收要求见 [个人使用与联网范围](09-local-and-network-scope.md)。

## 主流程与界面

导入 PDF/DOI → 核对元数据 → 选择模型、外发范围与预算 → 段落翻译或全文队列 → 双语阅读/图文注释 → 证据摘要 → 收藏笔记 → 选择引用样式并导出。

桌面工作区：左侧文献库与标签，中间原文/译文同步视图，右侧术语、图文注释、摘要和证据。任务中心显示进度、预算、取消与错误。小尺寸桌面窗口改为原译文切换与抽屉面板，保留返回证据的入口。常用功能支持键盘、选中文字及屏幕阅读器；中文字体由合法授权字体提供。

## 引用格式边界

输入交换格式与输出排版标准是两件事。CSL-JSON 为标准化工作元数据；BibTeX/RIS 保留原始字段与转换损失记录。引用样式以明确版本存储，GB/T 7714-2015 是兼容目标，不宣称为所有学校当前默认标准。学校模板、期刊投稿规范和 CSL 样式需逐条核对；首期输出纯文本、BibTeX、RIS、CSL-JSON，Word 动态引用与 LaTeX 插件后续开发。

## 初始质量门槛（待基准验证，非现有成绩）

建立 60 篇/至少 600 页合法测试集：30 原生 PDF、15 扫描、15 混合；涵盖双栏、公式、表格、跨页段落、旋转页和图内文字。至少两位研究者人工标注；争议样本复核。测试集不含保密或未授权传播材料。

- 原件字节保持 100% 不变；公式、数据图和数值不因翻译被静默改写。
- 原生 PDF 可读块覆盖率 ≥98%；按标注段落计，不以字符数掩盖遗漏；遗漏页必须被告警。
- 人工抽查至少 300 对段落，95% 无影响理解的严重译错；数字/单位/否定词严重错误为阻断项，阈值需与学科专家确认。
- 导出的布局碰撞/溢出页比例 <1%；所有发现的溢出可降级、不可静默裁切。图文遮挡属于阻断项。
- 摘要来源锚点可点击率 100%，人工证据支持率 ≥95%；锚点存在不等于语义支持。
- 引用样式至少 40 个金标条目：期刊、会议、图书、学位论文、数据集、中文作者和缺失 DOI；关键字段不得丢失，已覆盖样式与金标一致。
- 性能测量以 4 核/16GB/SSD、CPU-only、指定平台和版本为基线：1,000 条库检索 P95 <300ms，打开缓存页面 P95 <1s；全文翻译耗时另计网络、模型和页型，首轮基准后设置阈值。
- Windows、macOS、Linux 各测安装、导入、选段翻译、图文注释、断网恢复、引用与删除；CI 核心测试通过不等于端到端跨平台通过。

## 明确不做（不作为默认后续路线）

学术搜索平台、盗版下载、替作者代写论文、自动判断科学结论真伪、强制监控学生、自动将私人文献公开、多用户商业 SaaS、浏览器端、团队服务、账户云同步，以及承诺所有 PDF 无损翻译。

## 产品风险与决策

文献内容可能侵权或保密，云端处理由用户按文献授权选择；高风险稿件默认仅本地模型。选择模型前显示提供商、上传内容类型与费用承担方。用户论文及译文不自动落入本软件的 AGPL 许可。应用允许用户导出/删除本地数据，平台遥测默认关闭。
