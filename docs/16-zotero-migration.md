# 从本机 Zotero 迁移

文献库 → **导入与导出** → **Zotero 资料目录** → 选择资料目录 → 检查并预览 → 勾选条目 → 迁移。先退出 Zotero。资料目录包含 `zotero.sqlite` 和 `storage`；可从 Zotero 设置中的“显示资料目录”找到。

## 当前迁移范围

| 来源内容 | 当前结果 |
|---|---|
| 期刊论文、会议论文、图书、学位论文 | 通过现有字段校验后创建新书目；保留作者顺序、姓名、标签与可适配字段 |
| 集合层级、多集合归属 | 创建新集合树，不与已有同名集合自动合并；不合法名称的子树留存档案并报告 |
| 受管且可读取的 PDF | 创建独立附件身份；同字节文件共享本地对象，保留原父条目归属 |
| 受管的其他文件、独立附件、未适配父条目的文件 | 保存真实文件字节到本地迁移档案，可从收据中导出；不执行 HTML 或其他内容 |
| 其他文献类型、额外字段、原始时间及来源身份 | 存为可查看的本地原始档案；不伪装成已支持的原生类型 |
| HTML 笔记、PDF 批注文字、位置与关系 | 保存原始数据库记录，纯文本查看；尚未恢复为可编辑笔记或阅读器标注 |
| 原回收站状态 | 已适配条目保留回收状态；原始状态同时归档 |
| 链接文件、远程 URL | 保留来源信息；链接文件路径授权与复制仍待实现，远程内容不下载 |
| HTML 快照的伴随资源、批注缓存图片 | 尚未完整复制；不能宣称图像或快照已恢复 |
| 保存搜索、库设置 | 全选时保留原始记录，尚未适配成本软件的可执行规则 |

部分勾选只保存所选条目及其传递子项、相关集合祖先和使用到的字段值、作者与标签。全选时保存已支持读取的整个来源图谱及空集合。迁移收据分别显示原生活动/回收条目、PDF 和档案数量；档案计数不等于原生功能恢复。原库中的 Word 引用链接及 Zotero 同步身份不会因此转换为 PolyScholar 功能。

## 数据与失败处理

不通过 SQLite 打开源数据库。先确认普通文件，再使用禁止符号链接的非阻塞只读句柄将数据库和已有 WAL、SHM、journal 复制到私有暂存区，复制前后检查文件身份与哈希；恢复、完整性检查及 SQL 查询仅针对副本。模型/API/云同步不参与迁移。

PDF 原生校验在可取消的隔离进程中执行，最多 10 秒且不超过预览剩余预算；校验失败或超时只保留档案字节并报告。预览令牌与完整快照绑定，提交前再次检查来源和附件。原生记录、集合关系、来源映射、档案及固定审计记录在一个 SQLite 事务中提交。失败清理本轮新对象，不删除已有共享对象。取消在副本读取、文件复制与提交前检查；提交完成后以真实收据报告成功，不能当成取消回滚。迁移后原 Zotero 目录继续受导出防覆盖保护。

SQLite 本地存储升级为 v12，旧库先备份。迁移收据重启后仍可查看，来源条目身份与本地新 UUID 分开保存。同一来源快照不重复提交；增量同步、合并旧迁移和迁移撤销尚未实现。

当前数据库结构版本白名单为 121、123、130，并检查必要命名列和关系；未知结构拒绝，不按一个版本区间猜测兼容性。此白名单不是所有 Zotero 客户端版本均已验收的声明。

限制：数据库及每个侧车文件 256 MiB、10000 条来源条目、500000 行、原始档案 64 MiB；每个受管资源 100 MiB、资源总量 1 GiB。超限明确拒绝或报告不可用资源，不静默截断原始记录。

## 验证边界

合成 SQLite/WAL 测试与源代码 Qt 回归验证原库不改写、来源漂移拒绝、多父条目共享 PDF、事务回滚、部分选择、重启收据和原始 HTML 纯文本查看。

官方 Zotero 10.0.5 在独立 profile/data 目录创建的实际空库已读取：userdata 130，源数据库及侧车哈希未变。空库只证明实际结构可读取，不能作为带文献、集合和附件的真实迁移验收。当前 Mac 锁屏使交互式合成库创建受阻，真实包含条目/附件/批注的 Zotero 资料库验收仍开放。

三平台冻结安装包、真实翻译/API、Windows ACL 和凭据崩溃清理继续按 [整改追踪](14-review-remediation.md) 验收。

依据：[Zotero 资料目录](https://www.zotero.org/support/zotero_data)、[数据库只读访问](https://www.zotero.org/support/dev/client_coding/direct_sqlite_database_access)、[批注存储](https://www.zotero.org/support/kb/annotations_in_database)、[SQLite WAL](https://www.sqlite.org/wal.html)。
