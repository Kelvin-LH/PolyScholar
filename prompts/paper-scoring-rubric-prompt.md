# 提示词:生成《论文评分量化打分文档》

> 使用方法:把本文件全文粘贴给 GPT(或其他 LLM),它将产出一份《论文评分量化打分文档》。
> 生成后请将产物保存为 `rubrics/paper-scoring.md`,供后续 agent 评分时作为唯一依据读取。
> 若生成结果缺少本提示词要求的任一章节,把缺失章节的名称原样发回给它要求补齐。

---

你是一名学术评审方法论专家。请为我生成一份《论文评分量化打分文档》,用于让**不同的 AI agent、不同的 LLM** 对同一篇学术论文(以 arXiv 预印本为主)独立评分,并尽可能得出一致的结果。这份文档是评分的唯一依据,评分 agent 不允许引入文档之外的隐性标准。

生成版本 1.1.0，保留每条 0–5 整数、连续前置条件计分。旧评分保留旧版本，不能自动重评分。

## 文档必须覆盖的重点维度(总满分 100)

1. **创新点**(是否提出了新问题、新方法或新视角;与既有工作的实质差异)
2. **创新程度**(渐进式改进 / 组合式创新 / 开创性贡献的区分与判据)
3. **实际效果**(实验证据强度:基线对比是否公平、数据集规模与代表性、消融实验是否充分、结果是否支撑结论、可复现性信号)

固定五维权重：创新点 25（N1–N5）、创新程度 20（D1–D4）、实际效果 40（E1–E8）、方法严谨性 10（R1–R2）、清晰度 5（C1）；说明理由。

创新程度须提供形式和实验两种明确的高分证据路径。实验证据须说明机制、匹配近邻/简单替代和预算控制，不能只凭更高平均分、实现成本或知名度推断不可替代。实际意义须区分应用、方法/探索、理论及混合主张：应用主张需要预定义的阈值/约束与联合判定，方法主张可用具体性能—资源权衡、规模或任务能力及匹配对照；不要求所有方法论文提供应用收益阈值。盲评前冻结各主张的类型、路径及原文依据，禁止挑选有利路径、虚构阈值或把方法性能外推为部署收益。E4 不确定性等其余证据要求不因更换路径放宽。

## 文档必须包含的章节(缺一不可)

### 1. 维度与权重表
每个维度:名称、权重、考察要点清单、明确不计分的事项(如页数长短、 venue 级别单独不加分)。

### 2. 高考式分档锚点
总分与每个维度各设 5 个分档(例如:卓越 / 优秀 / 合格 / 欠缺 / 严重缺失),每档给出:
- 分数区间;
- **可观察的客观特征描述**，落到条目连续条件（如对照的协议、预算及不确定性是否可核对），不以数据集数量或 SOTA 字样直接决定档次；禁止使用"较好""一般"这类无锚点措辞;
- 相邻档之间的判定规则(同时满足哪些特征才可进档)。

### 3. 评分细则:得分点与失分点清单
每个维度列出典型得分点(按可引证的行为描述)和典型失分点(如:仅口头声称创新无对比实验、数据集单一、缺少消融、结论超出证据范围)。失分必须对应条文,不得凭印象扣分。

### 4. 三子代理盲评流程(参照高考阅卷)
- 三个子代理**互相不可见**,各自独立读取论文全文与本文档,独立输出完整评分;
- 每个子代理必须为每个维度的得分**引用原文证据**(章节号或原句摘录);
- 汇总规则:三个总分取**中位数**，并保留该代理完整五维结果，平分按 A/B/C 选择；总分极差 >10，或关键条目 D1–D4、E1、E3、E4、E6、E7 的 0–5 分极差 ≥2，触发一轮独立复核。门槛是流程规则，不能称作统计校准结果。复核仍超限时保留中位数并标记未解决分歧，不能无限复核或要求趋同。
- 汇总时同时输出三份子评分原文,不得只给最终分。

### 5. 跨模型一致性纪律
- 所有判断必须落到锚点与原文证据,禁止依赖行文风格、篇幅、自信语气打分;
- 明确"无法核验"的处理(如论文未提供代码链接,按锚点扣对应分而不是猜测);
- 建议评分 temperature 与自检步骤(输出前对照锚点逐项自检)。

### 6. 机器可读输出格式(JSON Schema)
定义评分报告的 JSON 结构,程序将直接导入。必须包含:
```
total(0-100 数值)、dimensions:[{key,name,max,score,rationale}],
strengths:[{point, evidence}], weaknesses:[{point, evidence}],
rubric_version:"1.1.0", manifest:{冻结版本/哈希/来源、effect_context、meaningfulness_basis等},
dimensions:[每维包含完整criteria:{id,score,rationale,evidence}],
sub_scores:[{agent_id,total,original_output:完整首轮对象,recheck_output:完整复核对象或null}],
aggregation:{method:"median",spread,initial_spread,initial_critical_items,critical_items,
             rechecked:boolean,rounds,selected_agent_id,unresolved_disagreement,recheck_reason}
```

## 生成要求
- 文档为中文,面向执行评分的 AI agent,指令式行文;
- 所有分数标准必须可操作、可对照、可复现;
- 篇幅以"评分 agent 一次读入即可执行"为限,宁可精炼不可堆砌。
